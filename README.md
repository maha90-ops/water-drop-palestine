# 🇵🇸💧 رحلة قطرة ماء في فلسطين

موقع تعليمي تفاعلي تكيفي لدرس **«دورة المياه في الطبيعة»** للمرحلة الأساسية،
يعالج الفاقد التعليمي باستراتيجية **السقالات التعليمية** مع التعلم التكيفي والتلعيب والهوية الفلسطينية.

## التشغيل
افتح `index.html` في المتصفح مباشرة، أو شغّل خادمًا محليًا:

```bash
cd water-journey && python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

لا يحتاج إلى خادم خلفي؛ يُحفظ تقدم الطالب في `localStorage`.

## البنية
| الملف | الدور |
|---|---|
| `index.html` | تطبيق الطالب (الشاشات تُرسم من `js/app.js`) |
| `teacher.html` | لوحة المعلم (بيانات تجريبية + الطالب المحلي) |
| `js/data.js` | المحتوى: المهارات، المراحل، التشخيص، بنك الأسئلة (٣ مستويات)، السقالات، المعلومات، الأوسمة |
| `js/clock.js` | الساعة الفلسطينية الحية (وقت الجهاز الحقيقي، تحديث كل ثانية، أجواء حسب الوقت) |
| `js/tasks.js` | أنواع المهام (اختيار، ترتيب، ربط، تصنيف، سؤال بصري) + الأنشطة الموجّهة |
| `js/app.js` | الشاشات، المحرك التكيفي، السقالات، البازل، التقرير، الشهادة |
| `js/visuals.js` | الرسوم SVG والشخصية ولوحة البازل |
| `js/store.js` / `js/ui.js` | الحفظ المحلي / النوافذ والإشعارات والقراءة الصوتية |
| `assets/clock-face.webp` | صورة الساعة المطرزة الأصلية بعد إزالة العقارب المطبوعة منها |

## المحرك التكيفي باختصار
- **التشخيص** (٧ مهام) ← مستوى لكل مهارة: 🟢 ≥ ٨٠٪، 🟡 ≥ ٥٠٪، 🔴 أقل من ذلك.
- **المسار**: 🟢 تحدٍّ (يبدأ بصعوبة ٢، يكفي نجاح مستقل واحد) • 🟡 تدريب • 🔴 دعم (صورة توضيحية مسبقة + تلميح ظاهر في أول سؤال).
- **السقالات عند الخطأ**: ١ تلميح ← ٢ صورة ← ٣ مثال محلول ← ٤ شرح متحرك ← ٥ نشاط موجّه، ثم يُعاد السؤال.
- **الإزالة التدريجية**: بعد النجاح بمساعدة يأتي سؤال «تحقق بدون مساعدة»؛ لا تكتمل المهارة إلا بنجاح مستقل.
- **الصعوبة**: ترتفع بعد كل نجاح مستقل وتنخفض بعد استنفاد السقالات.
- **التقرير**: قبل التدخل (التشخيص) • بعد السقالات (متوسط الأداء بمساعدة) • بعد إزالة السقالات (دقة الحل المستقل).
